A Schlage factory reset erases every user code and your custom programming code, then restores the default codes printed on the sticker that came with the lock. For most keypad models, the reset is: disconnect the battery, hold the Schlage button, reconnect the battery while still holding it, then release. Before you start, make sure you can find those default codes. Without them, you can't program the lock afterwards.

Before You Reset: 3 Checks

  1. Find the default codes. Look for a sticker on the inside of the lock (behind the battery cover) or in the user guide. You need the default programming code and user codes.
  2. Try the easier fix first. If you only forgot a user code but know the programming code, you can add a new code without resetting. If the lock just won't lock, a new battery or strike adjustment usually fixes it. See Schlage lock not locking from outside.
  3. Keep the door open and have the key handy throughout, so you can't lock yourself out.

Reset a BE365, BE375, FE595 or FE575

  1. Open the door and remove the inside battery cover.
  2. Disconnect the 9V battery.
  3. Press and hold the Schlage button on the outside keypad.
  4. Reconnect the battery while still holding the button. Keep holding until the Schlage button lights green and the lock beeps. Schlage's manual says to complete these steps within about 10 seconds.
  5. Release the button. The lock has now returned to its default codes.

Reset a Schlage Connect (BE468 / BE469)

  1. Open the door and remove the inside battery cover.
  2. Disconnect the battery pack.
  3. Press and hold the Schlage logo on the outside touchscreen.
  4. Reconnect the batteries while still holding it. Release when the lock signals. Schlage's guidance says the green check on the keypad and the inside Schlage button flash three times.
  5. Some guides add a final press of the Schlage button after reattaching the cover. If the lock doesn't respond to the default code, try that.

Z-Wave users: a factory reset can disconnect the lock from your hub or alarm system. Remove ("exclude") it from the hub first if possible, then add it again after the reset.

Encode, Encode Plus and Sense

These app-based locks are usually reset or re-added through the Schlage Home app (or Apple Home for Sense), and also have a hardware reset in the manual. Follow the instructions for your model, because removing the lock from your account and resetting it are separate steps.

After the Reset

  1. Test the default user code with the door open.
  2. Change the programming code so the default printed on the sticker can't be used by anyone else.
  3. Add your user codes. See our keypad lock guide for setup tips.
  4. Re-pair smart features (Z-Wave hub, Wi-Fi, app) and rerun handing calibration if prompted.
  5. Close the door and test locking and unlocking several times.

Reset Didn't Work?

  • Nothing lights up: try a brand-new battery and check the keypad cable connection.
  • Default code rejected: repeat the reset carefully, holding the button through the whole reconnect, and confirm you are using the codes for this lock (not a previous one).
  • Lost the default-code sticker: contact Schlage support with proof of purchase, or ask a locksmith.
